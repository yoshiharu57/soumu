# 業務日報・労務集計アプリ

建設コンサルタント業の技術者向けに、日々の業務時間を入力し、総務課で月次集計できる静的Webアプリです。

## 使い方

1. 1台だけで使う場合は `index.html` をブラウザで開きます。
2. 複数人で同じデータを使う場合は、共有PCで `python server.py --host 0.0.0.0 --port 8765` を実行し、表示されたURLを技術者に共有します。
3. 「マスタ管理」で業務名を追加します。
4. 「日報入力」で日付、技術者、業務、定時時間、残業時間を登録します。
5. 「月次集計」で業務別・技術者別に定時、残業、合計を確認します。
6. 必要に応じてCSV出力し、Excelで保管・加工します。

## 主な機能

- 技術者20名分の初期マスタ
- 業務マスタの追加・削除
- 日報の登録、編集、削除、検索
- 定時時間と残業時間を分けた登録・保存
- 日付・技術者ごとの1日合計、8時間までの残時間、超過警告
- 月間総時間、定時時間、残業時間、入力件数、稼働人数の確認
- 業務別・技術者別に定時・残業・合計を表示する月次総括表
- 業務別ランキング
- CSV出力、CSV読み込み
- 印刷用レイアウト
- 共有サーバー起動時の共通データ保存

## 注意

`index.html` を直接開いた場合、データはブラウザのローカルストレージに保存されます。`server.py` で起動した場合、データは同じフォルダの `data.json` に保存されます。どちらの場合も、定期的にCSV出力してください。

## 既存データとの互換性

- 従来の `hours` だけを持つ日報は、読み込み時に `regularHours`（定時）へ移行し、`overtimeHours`（残業）は `0` として扱います。
- 従来の `date, employee, work, hours` CSVも引き続き読み込めます。新しいCSVは `date, employee, work, regularHours, overtimeHours, totalHours` の6列です。
- ブラウザ保存データと共有サーバーの `data.json` は、次回保存時に新形式へ正規化されます。元の合計時間は変わりません。
- 更新後も派生値 `hours = regularHours + overtimeHours` を保存するため、移行中に旧画面が混在しても合計時間を読み取れます。
- 初回移行時は、ブラウザでは旧データを `roumuNippoApp.v1.legacyBackup` に、共有サーバーでは `data.json.legacy.bak` に一度だけ退避します。
